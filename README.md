# 📚 Library Management System (Python + Tkinter + MySQL)

A GUI-based Library Management System built using Python, Tkinter, and MySQL.
The application allows administrators to manage books, lend books to students, and safely process returns using a modern graphical interface with database-backed storage.

---

# ✨ Features

* 🔐 Password-protected access
* 📘 Register books under multiple categories
* 📤 Lend books to students using:

  * Student Name
  * USN
  * Book ID
* 📥 Secure return system with validation
* 🗄️ MySQL database integration
* 🎨 Modern dark-themed GUI
* 🖥️ Fullscreen responsive interface

---

# 🛠️ Technologies Used

* Python 3
* Tkinter
* MySQL
* mysql-connector-python

# ▶️ How to Run

## 1. Install dependencies

```bash id="g0jnqq"
pip install mysql-connector-python
```

---

## 2. Configure MySQL

* Create a MySQL database
* Import the provided `database.sql` file
* Update database credentials in `main.py`

---

## 3. Run the application

```bash id="t9xq8w"
python main.py
```
